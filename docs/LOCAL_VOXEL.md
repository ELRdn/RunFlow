# 問題箇所の局所ボクセル比較

保存済み原形状から、選んだ領域について1mm・0.5mm・0.25mm・0.1mmを比較する。全身モデルを置換する補修ではなく、細かさの変更で改善する問題を特定するための実験である。

## 条件

同じ原入力SHA、Blender 4.2.23、解析座標・尺度を使う。原形状全体に既存と同じ1µm頂点統合、重複・退化面除去、法線整合を行ってから、領域を選ぶ。各解像度はこの原入力から独立して生成し、粗い候補をさらに細分化する運用はしない。

測定領域に10mm・20mmの余白を加え、それぞれと交差する元の三角形を丸ごと保持して局所入力にする。生成側では三角形を切らず、切り口を塞がず、厚みを追加しない。この選択によって領域の外で面のつながりが切れる可能性は残る。実際に残った領域と元の面IDを保存する。

各局所入力には指定解像度のボクセル再メッシュを1回だけ実行する。adaptivityは0、体積保存補正は無効、平滑化なし。出力の退化面に接する頂点だけを、既存の1µm範囲で統合する。

## 切り出しによる影響の確認

同じ解像度の10mm余白と20mm余白を比較する。また、20mm余白の局所1mm版を保存済みの全身1mm候補と比較する。

同じ原形状の測定点から候補への距離の差と、投影面の対称差を使う。この診断では、測定点の距離差0.25mm・局所投影面積に対する対称差0.5%を感度の注意基準として記録する。これはCFDの2mm/1%条件を変更するものではない。

注意基準内でも、どの切り出し方でも同じになるという証明にはしない。異なる候補に対する原表面からの距離が等しくても、候補の形が同じとは限らない。全身1mm候補と一致しない局所実験の改善を、そのまま全身での改善と認定しない。

## 保存と比較

測定に使う表面は三角形を測定用の箱で正確に切り、切断面を塞がない。各小三角形の被覆半径0.25mmで距離を測り、双方向の分布と最大値の範囲を残す。これは局所的な形状診断であり、部位の意味や空気に接する面の分類は別に扱う。

投影面積は明示した1nmの2D精度格子で和集合を計算する。局所投影面積は全身の正面投影面積Arefではない。隙間では、保存済みの元の背景領域に新たに重なった面積を測る。正味の隙間面積の減少率と混同しない。

入力、余白、解像度、処理コード、固定版ツール、各候補、検査、費用、例外を非公開で保存する。元形状・保存済み全身候補・採用manifestは変更しない。全身への接続、閉鎖性・自己交差の全検査、CFD実行、科学的承認、ランキング採用は行わない。

## 実行

実対象の座標・対象ID・入力SHAは非公開のrequest JSONに指定する。既存出力は上書きせず、新しい非公開ディレクトリを使う。

```powershell
.venv/Scripts/python.exe scripts/run_local_voxel_comparison.py --request private/phase1-validation/local-voxel-request-001.json --output private/phase1-validation/local-voxel-001
.venv/Scripts/python.exe scripts/local_voxel_report.py --root private/phase1-validation/local-voxel-001
```

Blenderの準備・生成・距離測定は合計30分、投影・集計側の投影処理は合計15分を上限にする。段階ごとの上限、メモリ12GiB、出力10GiB、子プロセス終了を監視する。失敗は保存し、自動再試行はしない。今回追加された局所実験の枠であり、停止済みのCFD試験の60分枠を再開しない。

数値処理は合成した閉じた立方体で先に確認する。実対象での結果と解釈は、各出力ディレクトリの非公開レビューを参照する。

## 初回から得た制約

局所の細かい再メッシュは実行できたが、原表面の大幅な消失があり、補修として採用していない。選定した一点の距離が減ることや、元の隙間に重なる面がなくなることは、周辺の面が保持されたことを意味しない。面の消失量を必ず併記する。

2種類の余白で一致しても、全身の同じ解像度の結果と一致するとは限らなかった。両方の切り出しで同じ影響を受けることがある。この結果から全身の細かい再メッシュも同様に失敗すると断定せず、局所実験の適用範囲を限定する。次の補修では、元の表面を保った接続処理と、薄い面・内部面の扱いを検討する。
