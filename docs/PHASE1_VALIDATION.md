# Phase 1 継続：数値感度と走行周期

2026-09-08、ユーザーがPhase 1全体の継続と、余力があればBlenderでの追加形状修正を承認した。現状の収束済み1姿勢を出発点にする。旧試行・形状・許容差は保持し、数値的な成立、感度の合格、人間による科学的承認を分ける。

## 実行順序

1. 同一形状・同一流体格子で、一次風上とlinearUpwindV、limitedLinearVを比較する。定常収束を通過した値だけを比較に用いる。
2. 同じ方式で背景格子幅を基準の1.25倍・1倍・0.8倍とした3段階を比較する。表面・後流・裾付近の細分化levelを維持し、実際のセル数、壁面y+、境界層の生成状況も確認する。未達の細分化やセル上限による打ち切りを粗い格子の合格へ読み替えない。
3. 物体周辺の格子幅を保持し、外部境界の距離を基準の1倍・1.25倍・1.5倍で比較する。形状、流入、物性、壁関数を変えない。
4. 採用済み右接地位相・同じ256刻み・5周期ウォームアップで32時刻を二重取得し、偶数時刻が既存16時刻に一致するか検証する。8/16/32は同じ32点から間引く。新しい時刻は補間形状で代用しない。
5. 各姿勢の入力と補修を独立に記録して計算し、周期平均DragとCdAを同じ時間重みで集計する。失敗した姿勢を除いて平均せず、未完了なら周期平均はnullとする。
6. 誤差と費用を整理し、Blenderの局所編集は別候補として比較する。元の尺度・部位・姿勢を保持し、原本全表面2mm・正面面積1%と独立した接続・交差検査を引き続き用いる。人間の部位確認や科学的承認を自動発行しない。

一度に変える因子を明示し、結果に合わせて基準を緩めない。形状の基準不足は暫定計測の承認により保留中であり、感度が安定しても自動的には解消しない。

## 作業上の判定目標

最初の比較に用いる目標は、領域拡張によるCdA差1%以内、メッシュと離散化のCdA差3%以内、16/32時刻の周期平均CdA差2%以内。これらは今回設定する研究上の作業目標であり、人体空力の精度規格やユーザーによる科学的承認ではない。前提を満たす3格子では観測次数とGCIを併記し、非単調・未収束・不十分な細分化の場合はGCIを確定しない。点ごとの時間重みは周期末尾を重複させず均等にする。

一次資料: [NASAの格子収束・GCI](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)、[Foundation14の離散化](https://doc.cfd.direct/openfoam/user-guide-v14/fvschemes)。格子幅の比は1.25で、すべての方向と境界層厚へ同じ比を適用する。実メッシュは局所細分化と丸めを含むため、実効比と系統的な細分化の限界も記録する。
