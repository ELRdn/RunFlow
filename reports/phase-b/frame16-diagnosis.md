# 非閉鎖クラスが CFD 入場ゲートに落ちた理由（実測診断）

2026-09-14. 読み取り専用の診断である。形状も閾値も変更していない。

## 結論

2mm 距離ゲートを破ったのは形状差ではなく、**面積ゼロの退化三角形**である。
native Blender 表面に、3頂点が同一座標の三角形があり、その座標が修復後の表面から
39〜57 mm 離れている。したがって双方向距離の上限がその距離になり、既存の
`global_max_upper_m <= 0.002` が正しく拒否した。

BLOCKED（生成表面が非閉鎖）として記録されていた frame 5, 6, 16 の3本を診断した
ところ、**3本とも同じ形**だった。

## 証拠

| 5 | 3262276 | すべて `(-0.3654, 0.0612, 0.4869)` | 0 / 0 / 0 mm | 4.44e-16 m^2 | 42.46 mm | 8.26e-13 |
| 6 | 3695410 | すべて `(-0.1584, 0.0810, 0.6336)` | 0.0001 / 0.0001 / 0.0001 mm | 1.78e-15 m^2 | 57.21 mm | 6.72e-13 |
| 16 | 4039693 | すべて `(-0.0081, 0.0270, 0.4959)` | 0 / 0 / 0 mm | 5.41e-16 m^2 | 39.04 mm | 2.51e-13 |

3本とも、逆方向（candidate→source）は上限 0.955〜0.985 mm で余裕を持って通過して
いる。超過面積比はいずれも 1e-12 台で、絶対面積にして 1e-12 m^2 程度である。

frame 16 について近傍（±2mm）の source 頂点は 8 点しかなく、残り 3,800,335 点は
その点から 2mm より遠い。つまりこの座標は孤立した一点であり、周囲に本体形状がない。

## なぜ修復側に無いのか

Phase 1 の形状工程は、1µm の頂点統合と「面積ゼロ相当（1e-16 m² 未満）の面」の
除去を明記している（`docs/PHASE1.md`）。frame 16 の前段で使った
`repair_cycle_boundary_stitch.py` は、統合で潰れた三角形を
`welded[~degenerate]` で除去する。この退化三角形はそこで除かれ、修復後の表面には
対応する幾何が存在しない。

したがって 39〜57 mm は「形状がその分ずれた」ことを意味しない。面積 1e-16〜1e-15 m² の
退化面が、契約どおりに除去された結果である。

## 含意（Phase C の判断材料）

双方向距離の上限は、source に退化面が1枚でも残っていれば、その面の位置だけで
決まってしまう。自己交差クラス（4, 8, 12, 20, 24, 28）は通過したので、この形の
退化面は非閉鎖クラスの native 出力に固有である。

対応の候補は次の3つで、いずれも契約変更にあたるため本 Phase では実施しない。

1. 監査の source を「1µm 統合と退化面除去を済ませた表面」に固定する。
   `EXPERIMENT_PROTOCOL` §5 と `docs/PHASE1.md` の形状工程は既にそう記述して
   おり、現状の監査が raw な Blender 出力を source にしている点はその記述と
   食い違っている。既存フレームの監査を再取得し、差が無いことを A/B で示す必要がある。
2. 距離ゲートに面積下限を導入し、面積が閾値未満の source 面を評価対象から外す。
   新しい数値契約であり、A/B 実測が必要。
3. 非閉鎖クラスの native 出力そのものを直す（Blender 側の後処理）。ボクセル変更は
   比較家族を分けるため不可。

いずれも実測と版上げを伴うため、明示判断のうえで行う。
