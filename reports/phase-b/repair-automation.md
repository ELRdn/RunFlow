# Phase B - 形状修復の自動化（実測）

2026-09-14. 科学的閾値・収束条件・ランキング規則は変更していない。追加したのは
実行経路だけである。

## 問題

32姿勢のうち形状監査を通過したのは frame 0〜3 の4本だけで、frame 4〜31 は
全て失敗していた。内訳は2種類ある。

| 失敗クラス | 本数 | 例 | 症状 |
|---|---:|---|---|
| FAIL | 20 | frame-04 | Blender 0.9mm 表面は閉じているが Foundation `surfaceCheck` が自己交差を検出 |
| BLOCKED | 8 | frame-16 | Blender 生成表面が非閉鎖（frame-16 は境界辺120本、非多様体辺120本） |

frame-03 で有効だった局所操作（coplanar-fan 再三角形化）は手作業で中心頂点を
選んでいたため、そのままでは他フレームへ適用できなかった。

## 追加した経路

`scripts/run_phase1_repair_auto.py`（1フレームの修復ループ）、
`scripts/prepare_phase1_repair_frame.py`（修復＋形状監査＋マッピング行）、
`scripts/prepare_phase1_repairs.py`（複数フレームの並列実行と集約）。

1フレームの流れ:

1. 閉鎖性を辺の接続数で検査する。非閉鎖なら `repair_cycle_boundary_stitch.py`
   （1µm 未満の境界重複頂点のみを溶接）→ なお非閉鎖なら
   `repair_cycle_manifold_roundtrip.py`。それでも閉じなければ BLOCKED として返す。
2. Foundation `surfaceCheck` を実行する（`--checkSelfIntersection`）。
3. 証拠 tar から `selfInterPoints.obj` を取り出し、各証拠点の最近傍入力頂点を求める。
4. その頂点の入射ファンが単一の有向環で、環が診断上限内で平面なものだけを中心
   頂点として採用する。**面を共有する中心どうしは1回の呼び出しに混ぜない**
   （混ぜると閉位相が壊れる。実測で frame-12/20 が該当し、検出器として機能した）。
5. `repair_cycle_coplanar_fan.py` で環を再三角形化する。座標移動ゼロ、穴埋めなし、
   部位削除なし。環の座標は1つも変えない。
6. 再度 Foundation で検査する。閉鎖・自己交差なし・不正三角形なしの3条件が
   そろったときだけ採用する。残っていれば 3 へ戻る（上限6ラウンド）。

証拠点は Foundation が「問題のある三角形の内部代表点」として書くため、ファン中心
からの距離は三角形スケール（0.9mm ボクセルで実測 0.64mm）になる。探索半径は
`5µm → 50µm → 500µm → 1.5mm` の順に広げ、採用できた半径を記録する。
採用に至らなかった候補は理由つきで全て記録する。

## 形状監査の3面並列（実測）

監査段は被験体ごとに `source-to-candidate` と `candidate-to-source` の双方向距離、
3面投影、断面、可視点を要求する。投影3面を同時実行し、全て成功した後に
front, side, top の固定順で決定的に統合する。

| 段 | 実測（7フレームの範囲） |
|---|---:|
| source→candidate 距離 | 183〜241 s |
| candidate→source 距離 | 183〜241 s |
| 投影 front（並列時） | 1,114〜1,162 s |
| 投影 side（並列時） | 1,385〜1,444 s |
| 投影 top（並列時） | 1,429〜1,500 s |
| 投影3面の壁時計 | 1,430〜1,500 s（最遅面で決まる） |
| 可視点 | 28 s |
| 断面 | 14 s |
| 監査合計 | 約 1,900 s（32分） |

同じ3面を直列で流すと front+side+top = 3,929〜4,112 s なので、投影段は
**2.65倍**、監査全体でも約1.9倍になる。Phase A が frame-02 で測った 1.99倍より
効いているのは、この7フレームで3面の所要が揃っていたためである。

## 注意した点

- 精度グリッドは 1e-9 m のまま。Phase A の A/B で粗格子は4%遅いと実測済みで、
  監査スキーマ v2 は導入していない。
- 2mm 距離上限・1% 投影面積差・閉鎖性・自己交差の各契約は不変。
- 修復で座標を動かさない。環の座標は元のまま、中心頂点を除去するだけである。
- 失敗した候補・失敗したラウンド・中断した試行は削除せず残す。
- 資源ガード（空き RAM 8 GiB、D: 空き容量）はそのまま効かせている。並列度は
  このガードに従って決めた。
